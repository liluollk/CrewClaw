# 养殖场数字员工场景适配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在现有 CrewClaw Agent 平台底座上，将示例性的库存与改价工具替换为“养殖场生产协作与健康异常处置”闭环，保持平台定位不变，并让源码、README、演示和对外描述口径一致。

**Architecture:** 保留 Agent Profile、Workspace、Runtime Session、四段 Prompt、Memory、SessionRouter、Web/飞书/钉钉渠道、鉴权和权限确认等平台层。新增独立的养殖领域适配层，提供猪舍生产指标、异常观察、养殖规范和复检任务的模拟数据与领域函数；工具层只负责把领域函数暴露给 Pi Agent Runtime，并继续复用现有审计和确认回路。

**Tech Stack:** TypeScript、Node.js、Hono、React、SQLite、Pi Agent Runtime、TypeBox、Vitest、飞书、钉钉

---

## 基线和范围

- 基线提交：37b9128，当前工作区应保持干净。
- 本轮闭环：员工在群聊或 Web 上报猪舍异常，健康管理 Agent 查询指标、检索规范、记录观察并创建复检任务。
- 数据形态：使用可重复的本地模拟数据，不声称接入真实猪场 ERP、MES 或物联网设备。
- 业务安全：Agent 只做异常识别、规范检索和任务建议，不自动诊断疾病、开具处方或执行用药。
- 暂不实现：设备实时采集、复杂疫病模型、兽医处方、完整养殖 ERP、真实 IM 生产凭据、跨进程队列和商业指标统计。

~~~ts
export type RiskLevel = 'normal' | 'watch' | 'high';
export type TaskStatus = 'open' | 'done';

export interface PenMetrics {
  farmId: string;
  areaId: string;
  penId: string;
  batchId: string;
  measuredAt: string;
  feedIntakeKg: number;
  previousFeedIntakeKg: number;
  avgWeightKg: number;
  coughCount: number;
  diarrheaCount: number;
  temperatureC: number;
}

export interface HealthObservation {
  id: string;
  penId: string;
  reporter: string;
  symptoms: string;
  note: string;
  createdAt: string;
}

export interface InspectionTask {
  id: string;
  penId: string;
  assignee: string;
  reason: string;
  status: TaskStatus;
  createdAt: string;
}

export function queryPenMetrics(penId: string): PenMetrics | undefined;
export function evaluateHealthRisk(metrics: PenMetrics): { level: RiskLevel; reasons: string[] };
export function recordHealthObservation(input: Omit<HealthObservation, 'id' | 'createdAt'>): HealthObservation;
export function listHealthObservations(penId: string): HealthObservation[];
export function createInspectionTask(input: Omit<InspectionTask, 'id' | 'createdAt' | 'status'>): InspectionTask;
export function resetFarmState(): void;
~~~

固定夹具至少包含 A3 猪舍：采食量 182kg、前一日 207kg、咳嗽数量 8，并包含一个正常猪舍用于对照。风险判断只使用可解释的演示阈值：采食量下降超过 10% 或咳嗽数量大于 5 时为 watch，两个条件同时满足时为 high。代码注释必须说明这是演示规则，不是兽医诊断标准。
